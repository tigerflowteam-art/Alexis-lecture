# assets/

- `icons/favicon.svg` — icône de l'application
- `images/` — vide pour l'instant, accueillera les illustrations en V2
- `audio/` — vide pour l'instant, accueillera les voix enregistrées en V2

Les illustrations sont pour l'instant des emoji, rendus par le système :
zéro fichier à charger, disponibles partout, suffisants pour valider les
mécaniques.

En V2, la priorité de ce dossier est l'audio enregistré. Un enfant de cet âge
apprend la prononciation par imitation : il reproduira exactement ce qu'il
entend, défauts de synthèse compris.
